## 关键设计决策（已查证，勿推翻）

1. **凭据跳过而非迁移**：密钥环绑定机器+用户上下文，文件搬过去也解密不了（同学报告 03.3）。恢复/切换默认跳过 `.credentials.yaml`，防空壳覆盖真实凭据。用户要 Key 就在目标版本界面重录。
2. **preset 默认不跨版本带**：`anchored-standard` 等实验性 preset 是社区版 gateway 路由产物，官方版不认识。默认关闭 `include_presets`，用户明确需要才勾选。
3. **合并而非替换缓存**：扫描是探测性操作，历史发现记录比当次探测结果更可信。消失路径保留+标注，前端标灰，不静默丢。
4. **操作日志脱敏**：只记操作类型、环境、数量摘要、成功/失败、错误摘要；绝不记文件内容、不记凭据、不记 Key。

## 遗留与风险

- **凭据仍需手动重录**：这是 DSH 密钥环的安全设计，工具无法也不应绕过。切换/恢复结果里已有明确提示。
- **skills 共享库接管**：目前只提示，未强制接管 `~/.agents\skills`。若用户反馈官方版技能仍不可见，下一步考虑把共享库也纳入接管范围（需评估多版本共用的串扰风险）。
- **AIO 深路径识别**：模块⑤已保证深扫结果不丢，但若同学机器上深度扫描本身就没扫到 AIO，需要进一步排查扫描根目录覆盖。
