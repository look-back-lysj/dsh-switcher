# DSH Vault — DeepSeek Harness 备份、迁移与恢复工具

把 DeepSeek Harness 的对话、配置、技能、记忆、预设完整打包带走，换版本、换电脑都不怕。

---

## 快速上手（三步）

1. **体检**：打开应用，点「体检」，自动扫描本机所有 DSH 环境（不会修改任何文件）
2. **备份**：点「备份」，选择仓库位置，开始备份（自动排除缓存与依赖包）
3. **恢复**：点「恢复」，先预览再执行；默认只补缺，覆盖前自动保存快照

---

## 恢复策略（先懂再选）

| 模式 | 行为 | 适用 |
|---|---|---|
| 只补缺 | 已存在的文件一律不覆盖 | 默认，最安全 |
| 备份更新时覆盖 | 仅当备份比目标文件更新时覆盖 | 换新版本 DSH |
| 强制覆盖 | 无条件覆盖 | 整机搬家，谨慎 |

任何覆盖都会自动保存快照，可在「仓库」页撤回最近一次覆盖恢复。

---

## 数据范围

**会备份**：对话、技能、`.agents` 共享技能库、预设、记忆、团队配置、守卫快照、撤销点、配置、API Key 引用

**不会备份**：`node_modules`（首启自动重装）、插件市场缓存、壁纸引擎缓存、日志、GPU 缓存、账号登录 token（恢复后需重新登录）

---

## 换电脑（推荐流程）

1. 旧机：备份 → 「仓库」→ 导出备份包（zip）
2. 拷贝 zip 到新电脑（移动硬盘/U 盘）
3. 新机：「仓库」→ 导入备份包 → 全量校验
4. 「恢复」→ 选择来源与目标 → 预览恢复 → 执行

---

## 安全提示

- 仓库含全部对话与 API Key，**请勿上传云盘或发给他人**
- 恢复前会检查 DSH 是否在运行，避免写锁冲突
- 恢复失败会自动回滚本次已写入文件，并在仓库生成回滚补偿日志
- 回滚补偿日志可在「仓库」页查看与手动补偿（需二次确认）

## 常见问题

**Q: 提示「另一个 DSH Vault 正在操作」？**  
A: 有另一个备份在跑。等它结束；若确认没有，检查仓库里的 `.vault-lock` 是否残留。

**Q: 恢复后插件不见了？**  
A: 正常。插件本体（`node_modules`）不备份，首次启动 Harness 会自动重装（约 1-3 分钟）。

**Q: 恢复后需要重新登录 DeepSeek？**  
A: 是。账号登录 token 不备份（安全），API Key 会保留。

**Q: 能同时装几个版本的 DSH 吗？**  
A: 可以，用不同的 Home 目录（`DSH_HOME` 环境变量）。备份工具会同时发现它们。
